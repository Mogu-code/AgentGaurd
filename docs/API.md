# API Documentation

Base URL (local): `http://localhost:8000`
Interactive docs (auto-generated by FastAPI): `http://localhost:8000/docs`

## `POST /guard/authorize`

One-time, per-session natural-language authorization. Converts NL text into a
structured `AgentCapability` and returns a `session_id` + `capability_id` to
use for all subsequent `/guard/evaluate` calls.

**Request**
```json
{
  "nl_text": "Buy me a laptop for college, don't spend more than 70k.",
  "user_id": "user_1",
  "agent_id": "agent_1"
}
```

**Response**
```json
{
  "session_id": "sess_...",
  "capability_id": "cap_...",
  "capability": {
    "max_amount": 70000.0,
    "max_quantity": 1,
    "allowed_categories": ["electronics"],
    "approval_threshold": 49000.0,
    "max_daily_spend": 105000.0,
    "...": "..."
  },
  "extraction": {"extraction_method": "rule_based_v1", "...": "..."}
}
```

## `POST /guard/evaluate`

Evaluate a single agent-generated payment request against the stored
capability. Runs policy engine → ML risk/behavioral scoring → decision engine
→ (on ALLOW) Razorpay test/mock order creation → audit log append.

**Request**
```json
{
  "session_id": "sess_...",
  "capability_id": "cap_...",
  "amount": 38499,
  "quantity": 1,
  "category": "electronics",
  "merchant": "merchant_005",
  "merchant_known": true,
  "idempotency_key": "optional-custom-key",
  "simulate_timeout": false
}
```

**Response**
```json
{
  "request_id": "req_...",
  "session_id": "sess_...",
  "outcome": "ALLOW",
  "risk_score": 0.23,
  "behavioral_anomaly": false,
  "model_name": "random_forest",
  "model_version": "v1",
  "fallback_mode": false,
  "reasons": ["[ML] Risk score 0.23 below step-up threshold; no behavioral anomaly."],
  "required_action": "NONE",
  "request_summary": {"amount": 38499.0, "quantity": 1, "category": "electronics", "merchant": "merchant_005"},
  "razorpay": {"status": "created", "order_id": "order_mock_...", "used_mock": true, "raw_response": {"...": "..."}},
  "audit": {"prev_hash": "...", "this_hash": "...", "created_at": 1234567890.1}
}
```

`outcome` is one of `ALLOW`, `STEP_UP`, `BLOCK`. `required_action` maps
1:1 (`NONE` / `USER_APPROVAL_REQUIRED` / `PAYMENT_REJECTED`).

## `GET /guard/audit?limit=50`

Returns the most recent audit records (newest first), each with the
canonical payload and its hash chain position.

## `GET /guard/audit/verify`

Recomputes the entire hash chain from scratch. Returns
`{"valid": true, "records_checked": N}` or, if tampering is detected,
`{"valid": false, "broken_at_id": <id>, "reason": "..."}`.

## `GET /health`

`{"status": "ok", "ml_model_available": true, "model_name": "random_forest"}`
